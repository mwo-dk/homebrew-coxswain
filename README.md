# Homebrew tap for Coxswain

```sh
brew install mwo-dk/coxswain/coxswain              # terminal app (macOS, Linux)
brew install --cask mwo-dk/coxswain/coxswain-gui   # desktop app (macOS, Linux)
```

Installs [Coxswain](https://github.com/mwo-dk/coxswain), a Norton Commander style file manager
with Everything-speed search. The formula and the cask are updated automatically on each
release.
